Contexto:
Você está trabalhando em um sistema de gestão de aulas de dança chamado Bailado Carioca, feito em JavaScript puro, usando LocalStorage como banco de dados e interface em cards.
O sistema já possui módulos de Alunos, Turmas, Mensalidades e Caixa.

🔹 OBJETIVO

Implementar geração, visualização, salvamento e compartilhamento de recibos, usando uma linguagem humana, simples e profissional, adequada para WhatsApp e PDF.

🔹 TEXTO PADRÃO DO RECIBO (VERSÃO 3)

Use exatamente este texto como template:

RECIBO

Confirmo o recebimento de R$ {{valor}} referente a {{descricaoServico}},
pago por {{nomeAluno}}.

Forma de pagamento: {{formaPagamento}}
Data do pagamento: {{data}}

Com isso, dou plena quitação do valor recebido.

Bailado Carioca

🔹 REGRAS TÉCNICAS (OBRIGATÓRIAS)

NÃO salvar o texto do recibo no banco

Salvar apenas os dados estruturados:

{
  id,
  pagamentoId,
  nomeAluno,
  telefoneAluno,
  valor,
  descricaoServico,
  formaPagamento,
  data,
  tipo: "mensalidade" | "aula_avulsa"
}


O texto do recibo deve ser gerado dinamicamente a partir do template

O recibo deve ser:

Visualizável na tela (modal ou card)

Gerável em PDF

Compartilhável por WhatsApp (link wa.me com texto codificado)
