Você está atuando em um sistema financeiro em PRODUÇÃO INTERNA.
Implemente ferramentas de LIMPEZA CONTROLADA, sem quebrar histórico futuro.

Sistema: Bailado Carioca  
Perfil autorizado: ADMIN apenas

---

## 🚨 PROBLEMA REAL

Ao excluir alunos ou mensalidades:
- Recibos pagos permanecem
- Mensalidades antigas permanecem
- Dashboard continua exibindo dados antigos
- Não é possível “virar o mês” com base limpa

Isso NÃO é bug.
Mas o sistema precisa de ferramentas explícitas de limpeza.

---

## 🎯 OBJETIVO

Criar dois botões administrativos:

1️⃣ Limpar Mensalidades  
2️⃣ Limpar Recibos  

Com escopo CLARO, confirmação e segurança.

---

## 🧱 IMPLEMENTAÇÃO OBRIGATÓRIA

### 🔹 1️⃣ BOTÃO "LIMPAR MENSALIDADES"

Local:
- Aba **Mensalidades**
- Visível somente para ADMIN

Comportamento:
- Abre modal de confirmação
- Permite escolher:
  - Competência (MM/AAAA)
  - Status:
    - pendentes
    - pagas
    - todas

Ação:
- Remove mensalidades do DataStore
- NÃO remove alunos
- NÃO remove turmas
- Atualiza:
  - dashboard
  - filtros
  - totais
  - auditoria

Mensagem clara:
⚠️ “Essa ação é irreversível e afeta apenas mensalidades.”

---

### 🔹 2️⃣ BOTÃO "LIMPAR RECIBOS"

Local:
- Aba **Recibos**
- Visível somente para ADMIN

Comportamento:
- Abre modal de confirmação
- Permite escolher:
  - Competência (MM/AAAA)
  - Tipo:
    - mensalidade
    - aula avulsa
    - todos

Ação:
- Remove recibos do DataStore
- NÃO altera Caixa automaticamente
- NÃO recria mensalidades
- Atualiza:
  - listagem
  - dashboard
  - totais

Mensagem clara:
⚠️ “Recibos são comprovantes. Use apenas para reinício de período.”

---

## 🛡️ SEGURANÇA (OBRIGATÓRIO)

- Botões visíveis apenas para ADMIN
- Confirmação dupla (checkbox + botão)
- Texto explicativo no modal
- Nenhuma exclusão silenciosa

---

## 🧪 CRITÉRIOS DE ACEITE

- É possível zerar fevereiro antes de iniciar cobranças
- Dados de janeiro não vazam após limpeza
- Dashboard reflete corretamente
- Nenhuma outra funcionalidade quebra
- Sistema continua estável
