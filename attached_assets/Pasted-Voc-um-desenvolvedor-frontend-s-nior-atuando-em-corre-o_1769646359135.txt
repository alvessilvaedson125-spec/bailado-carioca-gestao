Você é um desenvolvedor frontend sênior atuando em correção de BUG funcional
em um sistema de gestão educacional já estável.

Foi identificado um problema REAL na área de Bolsistas do sistema Bailado Carioca:

1. Não é possível desvincular um bolsista de uma turma específica
2. Ao tentar vincular bolsista a mais de 2–3 turmas, as turmas deixam de aparecer
3. O campo "Turmas vinculadas" não reflete corretamente o estado real

---

## ⚠️ REGRAS ABSOLUTAS
- NÃO criar novas funcionalidades
- NÃO impor limite de turmas
- NÃO alterar regras de negócio
- NÃO alterar presença
- NÃO alterar financeiro
- NÃO alterar histórico
- NÃO refatorar o sistema inteiro

---

## 🎯 OBJETIVO
Corrigir o vínculo entre bolsista e turmas garantindo que:
- bolsista possa ser vinculado a QUANTAS turmas forem necessárias
- seja possível remover uma turma individualmente
- a UI reflita corretamente o estado real do DataStore
- as alterações sejam persistidas corretamente

---

## 🧱 AÇÕES OBRIGATÓRIAS

### 1️⃣ MODELO DE DADOS
- Garantir que `turmas_ids`:
  - seja sempre um array
  - nunca seja `null` ou sobrescrito por valor único
- Validar merge correto ao adicionar:
  - adicionar nova turma sem apagar as existentes
- Validar remoção correta:
  - remover apenas o ID selecionado

---

### 2️⃣ LÓGICA DE ADIÇÃO
- Ao adicionar turma:
  - usar concatenação segura (`push` / spread)
  - evitar sobrescrever o array inteiro
- Impedir duplicação do mesmo ID

---

### 3️⃣ LÓGICA DE REMOÇÃO
- Implementar remoção por:
  - `filter(id !== removido)`
- Persistir imediatamente no DataStore
- Atualizar UI após salvar

---

### 4️⃣ RENDERIZAÇÃO (BUG CRÍTICO)
- Garantir que TODAS as turmas vinculadas sejam renderizadas
- Remover qualquer:
  - `.slice()`
  - limite visual
  - `max-height` com overflow oculto
  - restrição de grid/flex que esconda chips
- Permitir quebra de linha automática (wrap)

---

### 5️⃣ TESTES OBRIGATÓRIOS
Testar manualmente:
- Vincular bolsista a 1, 2, 3, 4 ou mais turmas
- Remover apenas uma turma
- Confirmar que as demais permanecem
- Recarregar página e confirmar persistência

---

## 🧪 CRITÉRIOS DE ACEITE
- Não há limite de turmas por bolsista
- É possível remover qualquer turma individualmente
- UI reflete exatamente o estado salvo
- Nenhum outro módulo é afetado
- Sistema permanece estável

---
