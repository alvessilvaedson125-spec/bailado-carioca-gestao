## 🎯 OBJETIVO DA FEATURE
Implementar um **sistema de presença de alunos** que seja:
- simples de usar em aula
- rastreável (data, aula, aluno)
- justo para controle de bolsistas e frequência
- integrado ao sistema atual

---

## 🧱 MODELAGEM OBRIGATÓRIA (ENTIDADE PRÓPRIA)

Criar uma nova entidade no DataStore chamada:

presencas: []

Cada registro de presença deve conter, no mínimo:
- id (único)
- aluno_id
- turma_id
- data (YYYY-MM-DD)
- status: "presente" | "falta" | "justificada"
- tipo: "regular" | "bolsista" | "aula_avulsa" | "reposicao"
- createdAt

📌 NÃO duplicar dados do aluno ou da turma.
📌 Usar apenas IDs para vínculo.

---

## 🧠 REGRAS FUNCIONAIS IMPORTANTES

- Presença é registrada **por aula (data + turma)**
- Um aluno só pode ter **1 presença por aula**
- Presença NÃO altera financeiro automaticamente
- Presença NÃO altera status do aluno
- Presença é apenas registro e base para relatórios
- Alunos trancados ou excluídos NÃO aparecem para marcar presença

---

## 🖥️ UX DE REGISTRO (ESSENCIAL)

Criar uma tela ou seção chamada **“Presença”**, com:

### Fluxo principal:
1. Selecionar Turma
2. Selecionar Data (default = hoje)
3. Listar alunos ativos da turma
4. Para cada aluno:
   - botão rápido: Presente / Falta
   - opção Falta Justificada (opcional)

📌 UX deve ser rápido, com poucos cliques.
📌 Pensado para uso durante a aula.
